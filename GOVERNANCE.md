# Governance

Perqora is currently maintained by a single maintainer (the repository owner). This document describes the project's governance honestly rather than implying a foundation, board, or team that doesn't exist yet.

## Decision-making

The maintainer has final say on scope, architecture, and what gets merged. Contributions are welcome and reviewed in good faith; disagreements are resolved by discussion first, and by maintainer judgment when discussion doesn't converge.

## Becoming a maintainer

There's no formal process for this today, because the project doesn't have more than one maintainer yet. If you've made sustained, high-quality contributions and want to help maintain the project, open an issue and ask; this document will be updated if and when that happens.

## Changing this document

As the project grows past one maintainer, this file should be the first thing that changes, toward a more formal model (for example, a documented path to commit access, or a small steering group). Until then, it stays accurate to what actually exists.
